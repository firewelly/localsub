# 05 · 选型与实测结论

> 2026-11-16 ~ 11-18 在 Windows 11 + Intel Arc A770（Vulkan）实机验证。
> 本文只保留结论，不记录失败过程与个人素材信息；旧配置与旧模型未随仓库发布。

## 1. 最终定版

| 项 | 选择 |
|---|---|
| 听写 | Whisper **large-v3**（ggml fp16，2.88GB）+ Silero VAD |
| 翻译 | **Hy-MT2-7B-Q8_0**（7.43GB，llama-server / Vulkan） |
| 分片 | 10 分钟物理分片 + 流式抽取（长音频必需） |
| 批量 | 先全部听写，再单次加载翻译模型统一翻译；状态文件断点续跑 |
| 输出 | `ja.srt / zh.srt / bilingual.srt / report.json`，可写在视频同目录 |

配置见 `config/pipeline.json`，语言对由 `languages.source/target` 控制（默认 `ja`→`zh`）。

## 2. 整片对比（素材①：对白密集，166.7 分钟）

| 组合 | 听写 | 翻译 | 全流程 | 质检 |
|---|---|---|---|---|
| large-v3 + Sakura 7B | 701 条 / 25m19s | 零失败，1 条整句不译 | 28m07s | 1 error / 229 警告 |
| turbo-q8 + Hy-MT2 | 466 条 / 7m32s | 零失败 | 10m32s | 0 error / 191 警告（151 条超长 cue） |
| **large-v3 + Hy-MT2（定版）** | **701 条 / 25m19s** | **零失败、0 假名残留** | **~29 min** | **0 error / 236 警告** |

- 显存峰值：听写 1.07–3.2GB、翻译 6.2–8.6GB，合计 <10GB（16GB Arc 安全）。
- 结论：**听写用 large-v3，翻译用 Hy-MT2**；turbo 仅适合快速草稿，Sakura 偶发整句不译。

## 3. 听写模型对照（同 10 分钟片段）

| 模型 | 条数 | 耗时 | 观察 |
|---|---|---|---|
| turbo-q8_0 | 75 | 100s | 长句粘连、无标点 |
| turbo-fp16 | 56 | 74s | 略好，仍粘连 |
| **large-v3** | **125** | 244s | 有标点、断句正确，明显更准 |

结论：**参数量 > 量化精度**；turbo 两档都不足以替代 large-v3。

## 4. 为什么必须 VAD + 10 分钟分片（素材②：对白极稀，81.8 分钟）

- 该 whisper-cli（社区 Vulkan v1.0.0）的 VAD 在 **≥~35 分钟**音频上退化为 0 段；
- 关 VAD 整片跑：164 条中 140 条为幻觉（`ご視聴ありがとうございました` 等）；
- 10 分钟分片 + VAD + SRT 清洗后仅 2 条真实对白（素材本身几乎无对白）。
- 结论：分片是**正确性必需**，不是性能优化；每片模型加载约 2 秒，占比很小。

## 5. 批量与 IO 结论

- 两阶段批量可避免翻译模型反复加载；160 部规模下省去大量 20–60 秒的加载开销。
- 流式分片峰值本地占用约 1 片（10 分钟≈20MB），适合 SMB/NAS 源。
- 源盘不稳时可用可选暂存（`-StageDir`）；主流程默认直读源盘。
- 输出到视频同目录（`-OutputBesideSource`）：分片与翻译在本地完成，再回写源目录。

## 6. 适用与限制

- 引擎与流程通用；默认提示词、翻译模型与 QC 规则针对**日语→中文**调优。
- 换语言对需修改 `languages.*`、翻译模型/提示词，并调整 QC（假名检查仅 `target=zh` 启用）。
- 翻译质量为“准确可读”，非出版级润色；模型许可需自行核对。
