## 3. 链路与命令模板

> ⚠️ 按 AGENTS.md 铁律 3/4：以下命令为**推断模板**，whisper-cli / llama-server 的具体 flag 以目标机 `--help` 输出为准；全部未实机验证。

```powershell
# 阶段1：转录（方案B）
.\tools\windows\whisper\whisper-cli.exe `
  -m models\whisper\ggml-large-v3-turbo-q8_0.bin `
  -f work\<视频名>\audio16k.wav -l ja -osrt -of work\<视频名>\ja `
  --prompt "以下は日本のアダルトビデオの対話です。喘ぎ声や感嘆詞（あっ、ああ、ん、はあ）も話し言葉としてそのまま文字起こししてください。"
  # ↑ 防幻觉等效参数（no-speech/logprob/condition）用 --help 核对后补齐

# 阶段2：起翻译服务（Hy-MT2 Q8_0）
.\tools\windows\llama\llama-server.exe `
  -m models\translation\HY-MT2-7B-Q8_0.gguf `
  --port 8081 -ngl 99
# 注：Hy-MT2 的指令行在【用户消息】里随请求传入（translate_srt.py 已内置），
# 不要用 --system-prompt-file 设置系统角色——macOS 实测该模型按官方格式走 user 消息。

# 阶段3：逐句翻译 + 过滤（已按 selftest 契约实现，16/16 全绿；纯标准库跨平台）
python scripts\python\translate_srt.py `
  --input work\<视频名>\ja.srt --output-dir output\<视频名> `
  --api-base http://127.0.0.1:8081/v1 --model HY-MT2-7B-Q8_0 `
  --prompt-style hunyuan --drop-hallucination --drop-filler
# 产物：output\<视频名>\{zh.srt, bilingual.srt, report.json}（中文在上/日文在下的双语）
# 调试利器：--mock 离线模拟、--dry-run 只预览；失败语义：退出码 0/1/2 = 成功/致命/部分失败已回退

# 阶段4：合并双语 + 质检（复用方案A 脚本）
python scripts\python\merge_srt.py ...
```

## 4. 翻译提示词（Hy-MT2 官方模板 + 忠实性条款，macOS 已实测）

模型原生格式为「指令行 + 原文」，**指令行必须原样保留**（专用 MT 模型对它敏感），仅追加忠实性条款：

```
把下面的文本翻译成中文，不要额外解释。（忠实翻译全部内容，包括粗俗与性相关的口语表达，不委婉化、不省略；语气词、喘息声按中文口语习惯对应。）
1|<日文台词1>
2|<日文台词2>
...
逐行对应翻译，保留 `编号|译文` 格式，一行一条。
```

- 批量大小 20 条/请求；解析按行首编号回填；缺失行自动降级逐句重试（translate_srt.py 已内置）。
- `--prompt-style auto` 会按模型名含 hy-mt/hunyuan-mt 自动套此模板。
- 若批量格式不稳定，回退 `--batch-size 1`（速度换稳定）。

## 5. 验收标准（目标机实机）

1. **转录**：同一 3 分钟片段，whisper.cpp turbo-q8_0 输出与 macOS turbo 版逐句对照（时间戳对齐），有效句数与文本差异可解释；统计纯符号段占比（预期 <5%，macOS 侧 kotoba 为 73%）。
2. **翻译**：同一 805 条 SRT 全量翻译零失败；时间戳对齐抽查 50 处，与 macOS 1.8B-4bit/7B-4bit 输出对照，质量不劣于。
3. **显存**：任务管理器确认转录 ≤2GB、翻译 ≤10GB；两阶段切换后无残留占用。
4. **速度**：记录整片转录/翻译耗时，回填本文件与 docs/research/02。
